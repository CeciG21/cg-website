CG QA

A framework-aware quality gate for GitHub branch reviews and deployed stage environments. Deterministic findings, CI evidence and Playwright smoke checks remain separate from optional AI analysis.

GitHub compare APIFramework-aware checksPlaywrightOptional AI
THE PROBLEM

Quality signals are often scattered across tools.

Branch changes, CI output, deployment state and browser checks can all tell part of the story. CG QA brings those signals together without pretending that one score can replace engineering judgement.

THE APPROACH

Deterministic evidence first.

The workflow inspects changed files, applies framework-aware checks, separates CI evidence from stage-environment smoke checks, and keeps optional AI commentary clearly labelled as secondary analysis.

WHAT IT CHECKS

Branch and deployment evidence.

Examples include risky configuration changes, framework-specific patterns, missing tests, CI failures and Playwright smoke-test results against a deployed environment.

DESIGN PRINCIPLE

Explain the finding, not just the severity.

Each signal should make the evidence and next engineering action clear. Optional AI can help summarise or contextualise findings, but it does not override deterministic checks.
